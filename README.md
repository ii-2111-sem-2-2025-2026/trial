# Quiz 1 — Probabilitas Dasar (Autograded)

Repo ini adalah *starter code* untuk **Quiz 1 (Minggu 1)**. Kerjakan dengan melengkapi fungsi-fungsi di `src/quiz1.py`.

## Cara mengerjakan (mahasiswa)
1. Clone repo ini.
2. Buat virtual env dan install dependency:
   - `python -m venv .venv`
   - Windows: `.venv\Scripts\activate`
   - macOS/Linux: `source .venv/bin/activate`
   - `pip install -r requirements.txt`
3. Jalankan test:
   - `pytest -q`

## Aturan
- Jangan mengubah file dalam folder `tests/` (biasanya diproteksi oleh GitHub Classroom).
- Anda boleh menambah helper function sendiri, tetapi **jangan mengubah signature** fungsi yang diminta.

## Output yang dinilai
Nilai diambil dari hasil `pytest`. Setiap soal punya file test sendiri (Q1 s.d Q10).
